# CAN Logger Viewer — VSCode拡張

Vector CANoe/CANalyzer が入っていない環境でも、`.asc` / `.blf` 形式のCANログを
開いてトレース確認・信号デコード・グラフ可視化ができるVSCode拡張機能です。

固定のCAN IDに乗る要求/応答型のログデータと、それ以外の常時固定フォーマットの
CANフレーム（ビット位置ベースの信号定義、CAN FD対応）の両方をデコードできます。

## 主な機能

- ASC (テキストログ) / BLF (バイナリログ) の読み込み。ASC/BLFともClassic CAN /
  CAN FD 両対応（CAN FDの列構成は実CANoeバージョンによる差異まで網羅検証は
  未実施のbest-effort実装です）
- 「生ログ」タブ：Time / TX・RX / CAN ID / CONTENT のトレース表示、CAN IDの
  正規表現フィルタ、信号定義登録済みならパース済み表示・未登録なら生バイト列表示、
  CSVエクスポート
- 信号仕様の管理：CAN IDごとの信号定義（バイト位置・ビット位置・データ長・
  分解能・オフセット・バイトオーダー）をエディタ画面から編集、JSON入出力
- 複数マッピングプロファイルの管理と、論理チャンネル⇔実CAN IDの対応設定
- 「Logger」タブ＞テーブル：マッピングプロファイルを選んで項目単位のテーブル
  表示、値の上下限到達・未設定状態の検知と色分け表示、CSVエクスポート
- 「Logger」タブ＞時系列グラフ：項目を選んで重ね描画。実値／正規化表示の切替、
  上下限到達をマーカー表示、ホバーでの値ツールチップ
- 「Logger」タブ＞3Dグラフ：任意の3項目をX/Y/Z軸に割り当てて軌跡を3D表示。
  ドラッグで視点回転・ホイールでズーム・スライダーで時間スクラブ再生。外部
  ライブラリ非依存の自前SVG実装
- 大規模ログ向けの仮想スクロール（画面に見えている行だけをDOMに生成するため、
  件数によらず全件をスクロール可能）

## セットアップ

Node.js (LTS, 18以上) と VSCode が必要です。

```bash
npm install
npm run compile
```

VSCodeでこのフォルダを開き `F5` を押すと「拡張機能開発ホスト」が新しいウィンドウ
として起動します。そのウィンドウで:

1. サイドバーのCAN Loggerアイコンを開く
2. `sample/example.asc` を開く（Classic CANフレームに加え、後半にCAN FD
   フレーム（Logger 1/2、64バイトの固定フォーマットフレーム）のサンプルも
   含まれています）
3. 「生ログ」「Logger」タブを確認

> ⚠️ 信号仕様・マッピング等は**開いているワークスペースフォルダ内の
> `.canlogger/`** に保存されます。フォルダを何も開いていない状態（空のウィンドウ）
> ではサイドバーからの追加・保存はできません。その場合は「ファイル > フォルダーを
> 開く」で作業用フォルダを開いてください。

常用する場合は `npx @vscode/vsce package` で `.vsix` を作成し、
`code --install-extension can-logger-viewer-0.1.0.vsix` でインストールしてください。

## 使い方

- サイドバーの **項目仕様** から項目・分類を追加/編集（キーの重複は自動検知）
- **マッピングプロファイル** から新規プロファイルを作成し、各チャンネルの
  スロットに項目を割り当て。チャンネルに対応する実CAN IDは別画面で変更可能
- **固定フォーマットフレーム** から、常時固定フォーマットのCANフレーム
  （バイト位置・ビット位置・データ長・分解能・オフセット・バイトオーダー）を登録
- `.asc` / `.blf` を開くと自動的にビューアが起動。「生ログ」タブは登録済み
  CAN IDのみ内容をパースして表示し、「Logger」タブはマッピングプロファイルを
  適用したデコード結果を表示

## `.canlogger/` の書式

ワークスペース直下の `.canlogger/` にJSONファイル一式を保持します。各パネルの
「JSONインポート/エクスポート」ボタンから入出力でき、形式は `src/models/types.ts`
の型定義を参照してください。

## 既知の制限・今後の拡張候補

- BLFパーサーは公開情報に基づくbest-effort実装で、実際の Vector 製 .blf
  ファイルでの網羅的な検証は未実施です。値がおかしい場合は
  `src/parsers/blfParser.ts` 冒頭のコメントを参照の上、報告してください。
  なお、より稀な可変長CAN FDメッセージ形式 (CAN_FD_MESSAGE_64) には未対応です。
- マッピングのスロット⇔物理バイト位置UIをよりビジュアルに（表計算的な一括
  貼り付けなど）
